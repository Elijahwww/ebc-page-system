## 3. 可提取的方法（按价值排序）

1. **人群版本方法（3 主题一致）**：A/B/C 版本改变的是"首要动机 / 对比对象 / 度量单位 / 信任证据 / 模块顺序"，不是只换标题。
   - 例：原油 A `10美金 即可交易` vs B `0.01手起` `100:1`；ETF A 教育"为什么 ETF"，B 直接对照"国内买 ETF 的溢价/额度/管理费"。
2. **推广页骨架**：Hero → 监管条 → 产品解释×2 → 信任 → 品牌 → 三步 → 版权/风险 + 吸底 CTA，全部 CTA 指向同一注册弹窗（7/7）。
3. **Hero 公式**：两行 H1 + 一行副标题 + 单一 CTA + 酒红/黑底金属 3D 主视觉（7/7）。
4. **数字锚点 + 贴近数据的免责说明**（3 主题）。
5. **官网 vs 推广页职责分离**：官网补信息完整性（报价/时间/FAQ/指南），推广页做单一路径。
6. **本地化不是直译**：西语版删除"无税费"类卖点；日文版移除 FCA 监管卡。
