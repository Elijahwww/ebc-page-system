### 文案分析（INF）
1. **身份化利益**：A 用"做全球巨头的小股东"把抽象的 ETF 转成可感知的身份；B 用"一个账户"直接回应"跨境开户麻烦"；C 用"一键跟随万亿级基金策略"借用机构背书。三者对应三种人群的首要动机，是本案例最有价值的方法。
2. **对比叙事**：A/C 用"ETF vs 固收"，B 用"ETF CFD vs 国内买 ETF"（无溢价/无份额限制/无管理费）。对比对象随人群变化，而非产品卖点固定。
3. **数字锚点**：16.50% / 2%-5% / $16.83万 / 5:1 / 0 / 100+，每屏至少一个大数字。
4. **合规风险点**（NV，需合规确认）：
   - C 副标题"长期收益跑赢100%固收产品"属于收益比较承诺，强于 A 的"财富稳健增长"；
   - "无溢价""成本价购买ETF"对 CFD 的表述是否准确（CFD 不持有 ETF 份额，存在点差）；
   - "享有股息分配/持有ETF即享…红利"——CFD 为股息调整，不是持有份额；
   - "资金独立托管/最高级别资金保护"需有监管实体依据；
   - 页面版权为 SVG 实体，而监管条展示 FCA/CIMA/ASIC/FSCA（与 `ebc-data-flags`："主站由 SVG 实体服务，引用 FCA 需精确表述"一致）。
5. **5:1 杠杆**与美股官网设计图"5倍杠杆"一致，但与历史记录"股票CFD 产品页 1:20"存在冲突（见 05 报告 CONFLICT-04）。

## F. 案例价值

1. **最值得保留**：同一产品按人群拆 A/B/C 三版，且每版改变的是"首要动机 + 对比对象 + 模块取舍"，而不仅是换标题。
2. **解决的问题**：不同成熟度用户对同一产品的阻力不同（小白缺认知、国内 ETF 用户缺转换理由、存量客户缺新策略）。
3. **可参考方法**：Hero 身份化利益 → 对比证明 → 产品形式优势 → 活动 → 背书 → 三步；吸底条在首屏 CTA 离开视口后出现。
4. **仅适用于当前项目**：ETF 收益对比数据、"无份额限制/无申购上限"（针对 A 股 QDII 额度场景）、VGT/XLF 创意。
5. **值得改进**：
   - 活动截止 2026-09-12 已过，倒计时自动隐藏，但"0手续费 0隔夜利息""免息免手续费"仍在线（2026-11-11 抓取）——需确认活动是否延期（NV）；
   - C 代码 Hero 背景引用 `@img/ETF/a/bg.webp`（A 版的 VGT/XLF 图），而 C 设计图是 Vanguard/BlackRock/iShares 方块图 —— 线上视觉需核实（NV）；
   - B 版文案硬编码在模板中，`etf-b/locales/zh_CN` 中 word7/word8 等与线上不一致，`etf-b/locales/en` 为遗留文件（路由只开 zh）；
   - 设计图"纳指ETF 16.5%"与"标普500 实例"口径不一致（代码已修正）。
6. **证据不足的结论**：哪一版转化更好、活动对转化的贡献、流量来源与关键词 —— 无数据。
