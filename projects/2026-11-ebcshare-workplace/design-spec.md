# 已实现视觉与交互 v1

依据 pm-decision v2 与 Copy Sheet v1。适用集团内部工作平台，覆盖仓库营销页面的巨型 Hero、营销 CTA 和合作露出默认规则；不使用 FC Barcelona 联名组件。此为项目级覆盖，不修改全局设计系统。

| 项目 | 当前实现 |
|---|---|
| 品牌强调 | EBC 红 `#A52933`；主按钮、选中导航、少量强调 |
| 背景与文字 | 背景 `#F7F8FA`，卡片白，主文字 `#20242A`，次文字 `#626B75` |
| 结构 | 桌面 224px 侧栏、76px 顶栏、36px 内容边距；大屏内容边距 55px |
| 组件 | 16px 卡片圆角、1px 边框、轻阴影；按钮 hover、focus、disabled 明确 |
| 字体 | 系统字体，无外部字体请求；桌面 H1 30px、H2 18px、正文 14px、辅助 11–12px |
| 信息密度 | 首屏工具与公告优先，积分与最近访问放右侧；社区继续用图文卡片 |
| 断点 | 1250px 缩侧栏；1080px 图标侧栏；780px 单内容列；600px 移动底部导航 |
| 手机 | 两列常用工具、一列应用目录、可横向滚动的 Board 表格；弹窗适配窄屏 |

图片：伦敦天际线仅是示例团队故事配图，非 EBC 办公室证明；其余图文封面用 CSS 构造，不依赖外部加载。EBC Share 为文字组合标识，正式接入时可替换公司批准的品牌文件。
