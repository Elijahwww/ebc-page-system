# 已实现视觉与交互 v2

状态：VISUAL_V2_REVIEW_READY（Claude 重构，待用户评审；不是获批定稿）。依据 pm-decision v2 与 Copy Sheet v1；功能范围、文案词条（`dict` / ui-copy.json）与 v1 一致，本版只重建视觉层。

适用集团内部工作平台，继续覆盖仓库营销页面的巨型 Hero、营销 CTA 和合作露出默认规则；不使用 FC Barcelona 联名组件。此为项目级 Design Override，不修改全局 `design/`。

## 设计立场

一句话：**暖纸色桌面上的一张白色工作纸，EBC 酒红只出现在需要被看见的地方，数字用衬线体说话。**

| 借鉴对象 | 取用的原则 | 在本项目的落点（不是照搬） |
|---|---|---|
| Apple | 层级靠字号与留白，而不是靠边框 | 首页问候 62px、数字 60–68px；同屏卡片边框从 v1 的十余个减到必要的几个 |
| Linear | 外壳安静、内容浮起；键盘与状态反馈精确 | 侧栏与桌面同色，内容区是一张圆角工作纸；⌘K、焦点恢复、分段切换 |
| Notion | 内容像文档一样可读 | 公告用“日期 + 标题 + 来源”的编辑式列表，动态卡去掉外框只留图和字 |
| EBC 场景 | 跨时区、跨语言、活动密集 | 日期/时区进首页抬头；Board 用真实月度数据画应用插画；中英文同结构 |

## Token

| 项目 | 取值 |
|---|---|
| 桌面 / 工作纸 / 卡片 | `#F3F0EA` / `#FDFCFA` / `#FFFFFF` |
| 文字 | 主 `#1B1614`，次 `#5C5450`，弱 `#8B837D`；分隔线为主色 9% / 16% 透明度 |
| 品牌 | EBC 红 `#A52933`（沿用仓库候选值），深 `#7D1B25`，浅底 `#F7E9E7`，深色面上的高亮 `#E2707B` |
| 应用色调 | 翻译 红、Board 蓝 `#3457B2`、域名 紫 `#6B4BB8`、素材 绿 `#1F7A55`，各带浅底与中间色 |
| 状态 | 已开放 绿、只读 蓝、申请/审核中 琥珀（审核中呼吸）、建设中 空心灰 |
| 字体 | 正文与中文：系统字体栈（PingFang SC / Microsoft YaHei），无外部请求。数字、拉丁展示字：**Fraunces**（SIL OFL，自托管 `assets/fonts/`，两个 woff2 共约 148KB），回退 Songti / Georgia |
| 字号 | 首页 H1 40–62px；页面 H1 34px；区块 H2 20px；面板 H2 17px；正文 14px；辅助最小 11.5px（v1 存在 9–10px） |
| 圆角 | 8 / 12 / 18 / 22px；胶囊 99px |
| 阴影 | 三级；默认只有 1px 线，悬停和浮层才出现阴影 |
| 动效 | 进入 0.55s、悬停 0.2–0.5s；缓动 `cubic-bezier(.2,.8,.2,1)`，回弹 `cubic-bezier(.34,1.56,.64,1)` |

全部 token 在 `styles.css` 顶部 `:root`，样式按 13 个编号分区组织。

## 结构与页面

| 区域 | 实现 |
|---|---|
| 外壳 | 236px 侧栏与桌面同色；内容区为带 1px 线和 22px 圆角的工作纸；顶栏吸顶、半透明模糊 |
| 顶栏 | 面包屑（Board / 翻译显示“应用中心 › 当前页”）、搜索（聚焦展宽）、中/EN 分段开关、通知、头像 |
| 工作台 | 抬头：日期·时区 → 问候（名字用衬线斜体酒红）→ 说明；右侧本周日历卡含活动入口。其下：重要通知条 → 常用应用（标题行内嵌“最近使用”胶囊）→ 重要公告 + 深色成长卡 → 团队新鲜事 |
| 应用卡 | 上半为 CSS 插画：翻译是两张字卡、Board 是 `BOARD_DATA.months` 的真实柱形、域名是地址栏、素材是叠放色卡；悬停时插画各自动作，卡片上浮，高光跟随指针 |
| 成长卡 | 深色底 + 酒红光晕；等级环（320/500）、68px 积分、两个可点统计 |
| 团队动态 | 下划线主 Tab + 胶囊分类；无边框图文卡；右栏排行榜改为领奖台（前三）+ 列表，分享提示卡 |
| 通知公告 | 日期数字列 + 标题 + 来源标签；未读加粗带红点，已读降为次要色 |
| 应用中心 | 三列大卡；“更多工具”成为网格里的虚线占位卡 |
| EBC Board | 四项指标合并为一条指标带（60px 衬线数字）；月度柱状图可点选，选中为酒红、其余降透明度；交付范围条形；明细表整行可点 |
| 个人中心 | 深色横幅含等级环；偏好设置与访问申请两栏 |
| 浮层 | 弹窗缩放淡入 + 背景模糊；通知为右侧抽屉；应用详情顶部复用插画 |

## 响应式

| 断点 | 行为 |
|---|---|
| ≤1240px | 侧栏收为 68px 图标栏 |
| ≤1100px | 首页抬头单列；应用 2 列；各双栏布局改单列；Board 指标 2×2 |
| ≤780px | 侧栏变抽屉；顶栏只留菜单、搜索、语言、通知；底部悬浮胶囊导航；首页动态变横向滑动；Board 表格行变卡片（不再横向滚动）；弹窗与抽屉统一为底部上滑面板；输入框 16px 防止 iOS 缩放 |
| ≤360px | 首页应用单列 |

## 可见状态

| 对象 | 状态和反馈 |
|---|---|
| 应用 | 已开放、只读统计、申请访问、审核中、建设中（插画区斜纹）；收藏星标弹跳 |
| 点赞 | 心形填充 + 弹跳，计数即时变化 |
| 搜索/筛选 | 输入结果、无结果说明、清除筛选、筛选结果计数、分页边界禁用 |
| 公告 | 未读红点与加粗、阅读后降级、全部已读；侧栏与底栏未读提示同步 |
| 发布/申请 | 必填与长度校验（错误条抖动提示）、图片类型/大小校验、成功 Toast |
| 浮层 | 标题、关闭、Esc、焦点限制；关闭后焦点回到触发元素 |
| 重渲染 | 局部状态变化后恢复键盘焦点；进入动画只在切换页面或语言时播放一次 |
| 偏好 | 中英文切换、时区即时改变日期区域、默认首页持久化 |

`prefers-reduced-motion` 下关闭全部动画与数字滚动。已保留语义 HTML、skip link、`aria-pressed` / `aria-current`、可见焦点环；不宣称完整无障碍认证。

## 素材与边界

- 伦敦天际线仍是示例配图，非 EBC 办公室证明；其余封面与应用插画全部由 CSS 构造。
