# 已实现视觉与交互 v3

状态：VISUAL_V3_REVIEW_READY（Claude 重构，待用户评审；不是获批定稿）。依据 pm-decision v2 与 Copy Sheet v1.1。v3 针对用户 2026-11-12 的三点反馈：首页与侧栏功能重复、视觉“AI 感”重、日历混乱且无趣。

适用集团内部工作平台，继续覆盖仓库营销页面的巨型 Hero、营销 CTA 和合作露出默认规则；不使用 FC Barcelona 联名组件。此为项目级 Design Override，不修改全局 `design/`。

## 设计立场

一句话：**深色桌面托起一张冷灰工作纸；首页最上方是一片跟着本地时间变化的天空，四个办公室的时钟排在天空下，拖一下就能看别处几点。**

v2 的暖纸色 + 衬线斜体 + 圆润白卡被用户判断为“AI 感太重”，v3 整体弃用：

| v2 | v3 | 理由 |
|---|---|---|
| 暖纸色 `#F3F0EA` 桌面，侧栏同色 | 墨色 `#0C0D10` 桌面与侧栏，工作纸 `#F6F7F9` | 去掉米色调；深浅对比让内容区自己成为主体 |
| Fraunces 衬线数字、斜体名字 | DIN 风格系统数字字体（Bahnschrift / DIN Alternate），无斜体 | 衬线斜体点缀是最容易被认出的模板特征；DIN 数字更接近行情与时钟的语境 |
| 圆角 8 / 12 / 18 / 22，胶囊标签页 | 圆角 6 / 10 / 14 / 18，标签页 8px | 减少“气泡感” |
| 首页问候 + 小日历卡 | 天空舞台：问候、当前时间、四地时钟、时间轴 | 把“跨时区”这个真实场景变成首页的主视觉和主交互 |

## 日历的数据口径

- “今天”与本周由所选时区的真实日期计算，不再写死 11 月 9–15 日。
- 日期上的圆点 = 当天的公告条数 + 覆盖当天的“有日期活动”数。
- 附件 Board 数据只有月份，没有具体日期。因此右栏按月列出活动，并注明“来源数据按月份记录，不含具体日期”。
- 只有名称里自带日期区间的活动（如 “Global抽奖20261123-1225”）才会画成跨天条并进入当日安排，且标注“日期取自活动名称”。不为其他活动推测日期。
- 右栏每行的“N 项交付范围”沿用 Board 口径：范围，不是进度。

## 指令面板

`Ctrl/⌘ K`、`/` 或点击顶栏搜索框打开。输入即筛选应用、公告、动态；空输入时列出应用（按最近使用排序）、页面跳转和常用操作（发布动态、切换语言、管理应用、帮助）。↑↓ 选择，Enter 打开，Esc 关闭。取代 v2 “输入后回车、在弹窗里看结果”的搜索。

## 可见状态与无障碍

- 时间轴是原生 `range`，可用方向键每次移动 15 分钟；大号时钟对读屏隐藏，时间由四地时钟文本提供。
- 日历日期为按钮，带完整日期的 `aria-label` 与 `aria-pressed`；重渲染后焦点回到原按钮。
- 指令面板为 `role="dialog"`，Tab 焦点限制在面板内。
- `prefers-reduced-motion` 下关闭进入动画、视差、应用坞放大和时间轴复位缓动；时钟仍每秒更新。
- 其余状态（应用、点赞、筛选、公告、发布/申请、浮层）与 v2 一致。不宣称完整无障碍认证。

## 素材与边界

- 天空、日月、星星、山影全部由 CSS 渐变绘制，无图片。它表达的是“所选时区现在的钟点”，不是天气，也不代表各办公室的工作时间。
- 四个城市取自个人中心已有的时区选项，不代表 EBC 办公室的完整清单；正式接入时由 IT 按集团实际地点替换 `ZONES`。
- `demo/assets/fonts/` 里的 Fraunces 文件 v3 不再引用，可在确认不回退 v2 后删除。
- 伦敦天际线仍是示例配图。“EBC Share” 仍为文字组合标识，正式接入时替换公司批准的品牌文件。
- Board 所有数字、月份、交付类型仍来自 `data.js` 附件快照；“交付范围不等于完成进度”的口径不变。
