# Design Spec · 美股社媒推广页

- 版本：v0.2（含渲染后的视觉修订）
- 对应文案：`copy-sheet.md` v0.2
- 对应决策：`pm-decision.md` v0.2
- 页面模式：Persuade。社媒投放，移动端优先是渠道假设。
- 状态：`VISUAL_REVIEW_READY`（供人工看截图）。不是 `VISUAL_USER_APPROVED`。Demo ≠ Ready for Production。

## Art Direction

**采用：「时段牌 + 条件表」。** 这页唯一硬的视觉对象，是官网写明的那段交易时间，以及一张把「已看见 / 待确认」分开的条件表。首屏左侧是产品定义和唯一按钮，右侧是黑底时段牌。页面其余部分用白底、细线和左对齐正文，不做成行情热力图。

**拒绝：「深色涨跌幅看板」。** 大号百分比、霓虹涨跌和四张同权重卖点卡，会把内部选题「美股不错」画成收益承诺。没有行情接口，也不使用苹果或英伟达的产品照片。

**同时拒绝的模板：** 暖纸色加衬线、玻璃渐变、每屏三张白卡、合作伙伴 Logo 墙。Token 仍是仓库里的建议值，不是 Apple 的官方规格。

品牌红 `#a52933` 只给主按钮和焦点之外的行动。风险条用近黑底，避免整页都是红色。

## Header 与素材

- 类型：精简 LP Header。文字「EBC」，链到页顶。
- FC Barcelona 合作标识：不放置。投放市场的授权未知，仓库里也没有可安全重绘的官方文件。状态 `ASSET_REQUIRED`。
- 桌面显示三个页内链接：产品性质、交易条件、开户步骤。手机隐藏这组链接，避免和按钮争位置。
- 不跳转到跨域首页。

## 版面

| 区域 | 桌面 | 手机 |
|---|---|---|
| 风险条 | 首行，随页面滚动，不固定 | 同左，保证第一屏能读到 |
| Header | 固定。高度使用 token 72px | 高度 60px。只留品牌 |
| Hero | 左文右时段牌，牌与标题顶对齐。按钮在副标题下。三条边界是按钮下方的分隔线列表，不另做通栏三列 | 文案、按钮、三条边界、时段牌纵向排列。按钮在时段牌之前。标题强制断成「用差价合约参与 / 美股价格涨跌」，避免「涨」「跌」拆开 |
| 定义 | 并入 Hero，不单独成屏 | 同左 |
| 包含 / 不包含 | 两列文字 | 上下排列 |
| 条件表 | 两列表格 | 每行变成「条件名 + 说明」，不横向滚动 |
| 三步 | 三列 | 一列 |
| 吸底 | 主按钮离开视口后出现 | 同左，并给页面底部留出空间 |

容器宽度 1200px。字体是系统字体栈，不打包 SF Pro。

## 动效

吸底条出现时使用 150ms 透明度变化。`prefers-reduced-motion: reduce` 时取消。没有滚动视差，没有数字跳动。

## 交互

| 控件 | 行为 |
|---|---|
| 「查看开户说明」与吸底按钮 | 打开模态。标题与正文为 US-MODAL-001。不提交数据 |
| 关闭、Escape、点击遮罩 | 关闭模态，焦点回到触发按钮 |
| 「先看交易条件」 | 页内锚点 |
| 官网产品页链接 | 新窗口打开公开 URL |
| 无 JavaScript | 主按钮改为页内链接，指向 `#demo-fallback` 的同一段说明 |

## 与候选结构的视觉关系

信息职责来自 PM，不是来自历史 3D Hero。项目级视觉选择：用时段牌代替右侧表单或右侧装饰图。这不改变「按钮 CTA」的决定。
