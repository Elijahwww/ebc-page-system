# EBC Local-market reference registry

这里仅收录**有来源、地区范围、采集日期和状态**的市场特殊规范，供明确地区目标的项目按需读取。

- 普通全球页面不用加载所有地区资料。
- 日本等本地专属活动：先查是否存在对应的已核实规范；没有时由 Agent 自主调研当地同业和相关优质网页，保留真实来源，并将用户心理推演标为 `LOCAL_MARKET_HYPOTHESIS`。
- 每项市场特殊规则至少注明：所在地区/语言、适用渠道/用户、来源和日期、可直接观察到的内容、由此推断的建议、与通用 EBC 基线的差异、何时可能失效、是否经过人工确认。
- 页面整体逻辑、栅格、基础组件和语义事实默认复用，只对有必要的局部修改。
- 目前没有任何经确认的日本或其他单独市场正式规范；不要虚构。
