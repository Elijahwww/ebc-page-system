# Localization / EBC 多语言术语接入

> 状态：SOURCE_PENDING / NOT_BYPASSED。

## 当前事实
用户在历史对话中已提供一份 EBC 多语种术语库，并要求作为后续翻译基础。但在本仓库当前六个已集成分支里，**没有找到术语表的原始 CSV**，因此本项目不制造所谓“已经确认的 14 语种词表”或手工重建它。
**单语言中文 PM/Copy/Design/代码 Demo 测试不受此项阻塞。** 测试中不应声称已做真实多语种术语检查。

## 真实文件加入仓库后怎么使用
1. 在本目录保存原始术语 CSV（保留原文件并附版本/来源），生成只用于机器读取的规范化索引，不覆盖原始字段。
2. 核对简体中文/英文/其他语言的真实语言代码、产品术语、重复键/一词多义/上下文。
3. 把历史疑点单独登记为 TO_CONFIRM，由翻译或品牌语言负责人决定；禁止 AI 静默修正。
4. 正式文案在 PM/Copy 阶段确认后，以 Copy ID 和版本号为源，再按术语库翻译、长文本布局检查、多语言 QA。
5. 术语新增、驳回和改译都要保留来源、日期和适用地区，避免一次误改扩散到多语言。

## 当前 Agent 行为
- 中文页面：优先真实 EBC 已确认的中文文案和术语用法；
- 其他语言：若没有原始词表，明确标 `TERMBASE_NOT_AVAILABLE`，可提供候选译法，但不称之为“已按官方词库验证”；
- 设计时提前保证文本增长/换行容错；不伪造最终的地区产品命名或监管称谓。
