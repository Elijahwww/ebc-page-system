# Localization · 中文主稿、翻译与本地市场适配

> 本项目明确采用 **中文作为默认 PM / 文案审稿语言**；不代表默认中国市场。用户 2026-11-12 确认该流程。详见 [中文主稿与 Market Override](chinese-first-and-market-overrides.md)。

## 当前执行顺序
1. **中文主稿先完成**：PM 需求、调研、用户心理、方案与中文文案经历各自审查循环。
2. 中文文案确定后，将 Copy ID、版本、产品事实、CTA、不可更改的语义和上下文交给独立的翻译/本地化任务。
3. **翻译不是逐字直译**：目标语种可调整句法、语气和表达方式，但不能偷偷修改产品事实、信息职责或真实用户行为；如必须改变核心语义，返回 PM/Copy。
4. 页面结构、视觉栅格、响应式和组件尽可能共用；只有明确地区特殊需求才进行**有依据的局部** Market/Design Override。
5. **中文工作语言 ≠ 中国市场**：日本市场活动页从 PM 调研阶段就要依据日本当地的受众、渠道和行业参考，在中文内部审稿的同时保留日本市场逻辑。

## 多语种术语库状态
用户此前提供过 EBC 多语种术语表，但当前仓库没有可直接引用的原始 CSV，不应重建或编造“正式术语”。这不阻塞中文方案、中文文案和中文 Demo。实际开启目标语言翻译时，再导入原始词库并记录来源、语言码与版本。

## 地区特定规范
先按需查看 [markets/](markets/) 是否存在该地区有出处的已核实规范。目前**没有已批准的日本市场专门规则**。如不存在，Agent 应执行 `research/` 的跨行业外部研究，标记观察与 `LOCAL_MARKET_HYPOTHESIS`，不能假装当地要求已经确认。

## QA 边界
- **中文阶段**：中文信息、产品事实、用户路径、按钮与 Demo 的基础 PC/Mobile QA。
- **翻译阶段**：目标语种术语、语言自然度、语义等效、地区适配、字体/长文/断行及 CTA 核对。
- 没有词库或本地来源时可给候选，但必须标注 `TERMBASE_NOT_AVAILABLE` 或 `LOCAL_MARKET_HYPOTHESIS`。
