## 一、七大核心视觉与布局规范（v0.11.0）

1. **全站唯一统一字体（严禁 `monospace` 代码字体！）**：
   - 页面中**所有文字、股票/资产代码（如 `NVDA`、`XAUUSD`）、步骤序号（`01 / 02 / 03`）与财务/指标数字**，一律使用统一的 `--ui-font-sans`（`-apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", ...`）。
   - **禁止使用 `ui-monospace / Menlo / Consolas` 等宽代码字体**；数字对齐统一使用 `font-variant-numeric: tabular-nums`。
2. **Apple.com 级大屏版心与舒展垂直呼吸（告别窄条与扁挤）**：
   - PC 内容标准版心为 **`1200px`（`75rem`）**，宽视觉/Hero 版心为 **`1320px`（`82.5rem`）**；
   - 模块垂直留白保持舒展呼吸感：Desktop **`88px–116px`**（`clamp(5.5rem, 7vw, 7.25rem)`），Mobile **`64px–72px`**。
3. **Hero 大胆沉浸构图 + 卖点自由落位**：
   - **禁止在 Hero 放文字图表卡**；支持两种自然高冲击构图（按模型与题材自由选用，不锁死）：
     - **构图 A（居中全幅背景舞台）**：上方居中展示两行 H1 + 一行副标题 + 单一主 CTA，下方由高清全幅 3D/场景图自然托起视觉重心；
     - **构图 B（PC 左文右满出血融合 + 移动端上居中下全幅图）**：左右无缝渐变衔接，无硬边界割裂。
   - **监管与背书条松绑**：监管、执行与规模卖点按 [ebc-selling-points-library.md](../../content/selling-points/ebc-selling-points-library.md)（V14.1）根据受众与渠道自由决定放 Hero 底条还是 `Why EBC`，不硬塞挤压首屏间距。
4. **打破纯黑白单调：Bento 主次分层 + 微交互 + 跨模型优雅降级**：
   - 保持纯净中性表面（`#000000 / #161617 / #FFFFFF / #F5F5F7`，不乱铺大面积泥泞渐变），但**不做等大纯黑白文字盒子**；
   - **有商业级生图能力时（如 Codex / Gemini）**：卖点模块用 Apple Bento 主次分层，将核心卖点升格为大尺寸高光主卡（配独立定制 3D 透明底或满出血视觉）+ 精致次级卡，且 Hero 与 B1 分别独立生图、绝不撞图；
   - **无原生生图能力时（如 Claude Code）**：**严禁把 Hero 同一张底图反复复用给相邻的 B1 模块，也不要用简陋手绘 SVG 冒充商业 3D 图！** 优先复用上游 Agent（如 Codex）已生成的高质实图；若全无实图可用，B1 改用**「大号核准核心数字卡（如 `20ms` / `0.0 pips` / `5 年 100%` / `800 万+`）+ `1.5px` 线性 SVG Icon + 细腻边框/悬停微交互」**建立视觉层次。
5. **标的代码彩色识别 + 配图透明底/满出血与对齐铁律**：
   - 多股票/多资产矩阵（如美股科技股）必须配**对应品牌的彩色视觉徽标或高识别度色标**（单标的如黄金可用看涨/看跌双卡，按题材自然适配）；
   - **独立 3D 元素配图（形态 A）**：**必须使用真正透明底 PNG（Alpha 透明通道）**，严禁把带黑色或纯色矩形底色的 JPG/PNG 直接贴进卡片露出“黑框套灰框”；且透明底元素**必须与卡片内标题/Tag 排版轴线对齐**，不盲目随手居中；
   - **完整带背景的场景/渲染图（形态 B）**：**只能作为整张卡片或整个模块的满出血背景（Full-Bleed `object-fit: cover`）彻底融合**（文字区叠柔和遮罩保可读）；严禁左文右无容器散图，严禁相邻模块撞图。
6. **全页标题对齐统一 + 标题零逗号两行**：
   - **全页对齐一致性**：PC 端同一页面内所有模块的大标题必须保持同一套对齐体系（**全页居中**或**全页左对齐**），严禁上半页左对齐、下半页居中的视觉割裂；
   - **大标题零逗号拆两行**：Hero H1 与 Section H2 中间有逗号时，直接去掉逗号拆成两行展示（`<br />`）。
7. **移动端（`≤ 767px`）精简与居中铁律（v0.11.0 新增）**：
   - **移动端标题与副标题一律居中展示**（无论 PC 端采用左对齐还是居中，到了移动端统一居中，视觉更稳定大气）；
   - **移动端非 Hero 模块不设副标题**：除 Hero 区域在空间充足时可保留精炼副标题外，**移动端其他正文模块（B1 / B2 / B3 / M07 / M08）默认不展示模块级副标题**（直接“居中大标题 → 卡片”），大幅减少滚动疲劳、保持 Apple 级利落感；
   - 触控热区一律 `≥ 44px`，保障单手顺滑滚动。

## 三、组件精细规格（按钮 / 卡片 / 分割线 / Icon）

- **主按钮**：纯实心 `#A52933`（Hover `#8D212B`），胶囊圆角 `999px`，Desktop 高度 `48px–52px`（Hero），字重 `500`，零廉价亮红渐变光晕；次按钮 `1px solid rgba(0,0,0,0.16)`。
- **卡片**：圆角 `20px–24px`，PC 内边距 `28px–36px`，浅底 `#F5F5F7` 配 `1px solid rgba(0,0,0,0.06)`，深底 `#161617` 配 `1px solid rgba(255,255,255,0.10)`；悬停给轻盈边框提亮与 `translateY(-2px)` 反馈（尊重 `prefers-reduced-motion`）。
- **分割线**：统一 `1px solid rgba(0,0,0,0.08)`（浅底） / `rgba(255,255,255,0.12)`（深底）。
- **Icon**：统一 `24px`、`stroke-width="1.5"` 极细线性矢量，去厚重方块底托；重点位可用品牌红 `#A52933` 或主题微彩点缀打破全黑白沉闷。
