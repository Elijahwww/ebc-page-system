# EBC Apple-Grade 前端视觉与组件基础规范（v0.8.0 · 强制遵守）

> **状态**：**`MANDATORY_UI_BASELINE`**（2026-11-24 基于 PC 与 Mobile 真实截图完成二次校准）。
> **执行铁律**：任何后续页面与多主题 LP 必须**先严格遵守本规范与 [tokens-apple-ui.css](tokens-apple-ui.css)**，严禁跳过规范直接手改单个 Demo。

---

## 一、六大不可违背的视觉与布局铁律（v0.8.0）

1. **全站唯一统一字体（严禁 `monospace` 代码字体！）**：
   - 页面中**所有文字、股票代码（如 `NVDA`、`AAPL`）、步骤序号（`01 / 02 / 03`）与财务数字（`$1,158 亿`）**，一律使用统一的 `--ui-font-sans`（`-apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", ...`）。
   - **禁止使用 `ui-monospace / Menlo / Consolas` 等宽代码字体**（会出现斜杠零与打字机割裂感）；数字对齐统一使用 `font-variant-numeric: tabular-nums`。
2. **Apple.com 级大屏版心与舒展垂直呼吸（告别窄条与扁挤）**：
   - PC 内容标准版心为 **`1200px`（`75rem`）**，宽视觉/Hero 版心为 **`1320px`（`82.5rem`）**，彻底消除大屏两侧过宽的空白安全边距；
   - 模块垂直留白保持舒展呼吸感：Desktop **`88px–116px`**（`clamp(5.5rem, 7vw, 7.25rem)`），Mobile **`64px–72px`**，杜绝模块间拥挤粘贴。
3. **Hero 大胆沉浸构图 + 监管条解耦**：
   - **禁止在 Hero 放文字图表卡**；优先采用两种高冲击力构图：
     - **模式 A（推荐 · Apple Keynote 居中全幅背景舞台）**：上方居中舒展展示两行 H1 + 一行副标题 + 单一主 CTA，下方由大胆、高清的**全幅 3D 场景背景图（Full-Bleed）**自然托起视觉重心（手机端与 PC 端天然统一大气，绝不局促）；
     - **模式 B（宽容器左文右满出血/无缝 3D 视觉）**：仅在视觉元素具备完整容器或纯黑无缝融合时使用。
   - **监管模块（`M02`）松绑**：监管信息是可自由组合的信任卖点，**不再强制硬塞在 Hero 底部挤压首屏与第二模块的间距**（监管在不同页面与区域的自由组合规则将在下一版本专项定义）。
4. **打破纯黑白单调：Bento 主次分层 + 独立 3D 素材 + 微交互**：
   - 保持纯净中性表面（`#000000 / #161617 / #FFFFFF / #F5F5F7`，**不乱铺大面积泥泞渐变**），但**不能做成 4 张完全等大的纯黑白文字盒子**；
   - 卖点模块采用 **Apple Bento 主次分层**：将 1 个最核心卖点升格为 **大尺寸高光主卡（配独立 3D 无缝/透明底渲染视觉 + 细腻微光交互）**，其余卖点做精致次级卡并配微妙 hover/点击交互反馈。
5. **标的代码彩色识别 + 配图透明底/满出血与对齐硬规（v0.9.0 强制）**：
   - 股票/资产列表（如 `NVDA / AAPL / MSFT / TSLA / META / AMZN / AMD`）必须配**对应品牌的彩色视觉徽标或高识别度色彩微章**，严禁做成全黑白文字方框；
   - **独立 3D 元素配图（形态 A）**：**必须使用真正透明底 PNG（Alpha 透明通道）**，严禁把带黑色或纯色矩形底色的 JPG/PNG 直接放进卡片里露出“黑框套灰框”边界；且透明底 3D 元素**必须与卡片内文字/标签的排版轴线建立明确对齐关系**（如标题与标签居左时，3D 元素同步按左轴线或清晰网格锚点落位，不盲目随手居中）；
   - **完整带背景的场景/渲染图（形态 B）**：**只能作为整张卡片或整个模块的满出血背景（Full-Bleed `object-fit: cover`）彻底填满容器并自然融合**（文字区叠加柔和渐变遮罩保证可读性）；
   - **严禁**：① 单独放置带矩形底色的图片块；② “左边文字、右边孤零零放一张无容器承载的散图”。
6. **移动端优先与标题零逗号两行**：
   - 标题中间带逗号时，直接去掉逗号拆成两行展示（`<br />`）；
   - Mobile（390px）优先保障首屏呼吸感、两行清晰断句、触控 ≥ `44px` 与单手顺滑滚动。

## 二、字体与字重阶梯表（统一 `--ui-font-sans`）

|---|---|---|---|---|---|
| **Hero H1** | `44px–62px` (`clamp`) | `36px` | `600` | `1.08` / `-0.025em` | `#1D1D1F` / `#FFFFFF` |
| **Section H2** | `32px–44px` (`clamp`) | `28px` | `600` | `1.15` / `-0.022em` | `#1D1D1F` / `#F5F5F7` |

## 三、组件精细规格（按钮 / 卡片 / 分割线 / Icon / 微交互）

- **主按钮**：纯实心 `#A52933`（Hover `#8D212B`），胶囊圆角 `999px`，Desktop 高度 `48px–52px`（Hero），字重 `500`，零廉价亮红渐变光晕；次按钮 `1px solid rgba(0,0,0,0.16)`。
- **卡片**：圆角 `20px–24px`，PC 内边距 `28px–36px`（与 `1200px` 宽版心匹配），浅底 `#F5F5F7` 配 `1px solid rgba(0,0,0,0.06)`，深底 `#161617` 配 `1px solid rgba(255,255,255,0.10)`；悬停时给予轻盈边框提亮与 `translateY(-2px)` 反馈（尊重 `prefers-reduced-motion`）。
- **分割线**：统一 `1px solid rgba(0,0,0,0.08)`（浅底） / `rgba(255,255,255,0.12)`（深底）。
- **Icon**：统一 `24px`、`stroke-width="1.5"` 极细线性矢量，去厚重方块底托；在重点位置允许用品牌红 `#A52933` 或主题微彩点缀打破全黑白沉闷。
