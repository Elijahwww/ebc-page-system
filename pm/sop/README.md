# 内部 PM SOP 接入区

> 当前：`INTERNAL_PENDING`。用户计划提供内部需求处理 SOP、流程资料及不同部门要求。**现在没有正式 SOP 原文，不做臆测填充。**

收到后按以下顺序处理：
1. 原文件以受控方式保存，登记原始文件名、来源、Owner、版本与生效日期；不把敏感附件自动公开或上传。
2. 逐条提取真实责任边界、触发条件、前置材料、工单字段、审批角色、完成定义、例外与升级路径。
3. 对比 `pm/methods/` 中已有候选方法，产出 `aligned / added / conflict / pending` 差异表。
4. 生成可执行 `PM-SOP Skill` 和 QA 门禁草案；先交负责人确认后再标为 `APPROVED_RULE`。
5. 后续新版本保留变更原因、适用范围和历史链接，旧文档可回滚。
