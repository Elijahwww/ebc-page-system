## 三、基础防错底线（仅 5 条硬事实，避免低级错误）

1. **监管号与实体零出错**：引用监管号/实体名称时严格对照上表，不编造、不串行。
2. **不混淆 CFD 与实股**：不把美股/ETF CFD 写成“持有真实股票/成为股东/直接认购原始股”，不写错误金融常识（如“美股规避印花税”）。
3. **不复用已过期优惠**：历史“0 手续费 / 0 隔夜利息（截止 2026-09-12）”已过期，未经当次需求提及不要写入。
4. **不编造假实时行情与假榜单**：无真实行情 API 时不造假跳动价格或假收益榜；引用公开历史财报/市场数据时标明出处与日期即可。
5. **不遗留旧代码残留**：做新主题页面时不混入无关产品的 FAQ、旧文案或占位价格。
