# ITER-20261112-002 · 中文主稿优先，地区市场与工作语言解耦

- **触发**：用户明确补充，所有普通 EBC 页面方案和审稿先以中文为主；中文文案确定才进入翻译，翻译不是逐字直译。通用页面逻辑、UI 和组件优先复用，只有明确面向日本等地区的特殊活动才需读取当地市场规范。
- **V1 缺口**：原版没有强制区分工作语言与目标市场，可能因为中文主稿假定中国用户，或在中文阶段被迫处理所有语言；术语 CSV 状态提示被过度突出。
- **V2 改动**：
  1. `working_language=zh-CN` 默认。PM 需求、研究、用户推演、文案和方案以中文反复审查；确认中文 Copy Sheet 后再启动独立本地化。
  2. `target_market` 单独决定市场证据与用户路径。明确日本市场时，即使内部中文写作，也先研究当地行业页面/用户/渠道，不套中国大陆用户经验。
  3. 翻译时可本地化改写语言表达，但不能变动产品事实、信息职责和用户行动；有语义冲突返回 PM/Copy。
  4. 页面通用逻辑、视觉、交互与组件尽量共用；地区确有差异时才创建有来源的局部 Market/Design Override。
  5. 未提供的真实地区规范保留缺口；外部研究注明 `LOCAL_MARKET_HYPOTHESIS`，不凭模型记忆伪装批准。
- **修改文件**：`localization/chinese-first-and-market-overrides.md` 为中心，链接到 `AGENTS.md`、`PILOT.md`、PM/Content/Design 核心文档与 Skills；补充 `localization/markets/README.md`；README 将中文 Demo 的待办标题调整为“已知资源与能力边界”。
- **状态**：USER_CONFIRMED_WORKFLOW；实机 Agent 执行效果尚未测试。
- **回归场景**：普通中文官网产品页不提前翻译；日本定向活动页虽输出中文 Brief，也需日本当地研究证据，默认 UI 仅局部适配。
- **版本处置**：作为 v0.1 工作流增量，不声称已获公司正式多语种生产 SOP 批准。所有后续问题记录到 `iterations/`。
